# Inteligencia Artificial – Proyectos y Prácticas

Este repositorio reúne diferentes actividades, prácticas y proyectos
desarrollados durante la materia de Inteligencia Artificial.

El propósito del repositorio es documentar mi aprendizaje y la aplicación de
conceptos relacionados con análisis de datos, aprendizaje automático y
resolución de problemas mediante herramientas de Python.

## Contenido

Dentro del repositorio se encuentran trabajos desarrollados durante el curso,
así como documentación y archivos utilizados para experimentar con diferentes
técnicas de Inteligencia Artificial.

El contenido se encuentra organizado principalmente en:

- `Documents_IA`: documentos, prácticas y proyectos realizados durante la materia.
- `Certificates`: certificados relacionados con el aprendizaje y uso de
  herramientas de Inteligencia Artificial y Data Science.

## Tecnologías utilizadas

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib
- TensorFlow / Keras

## Conocimientos desarrollados

Durante el desarrollo de estas actividades trabajé con conceptos como:

- Limpieza y preparación de datos.
- Análisis exploratorio de información.
- Modelos de clasificación y regresión.
- Evaluación de modelos.
- Aprendizaje automático.
- Redes neuronales.
- Procesamiento y análisis de conjuntos de datos.

Este repositorio representa parte de mi formación en Inteligencia Artificial y
muestra mi interés por continuar desarrollándome en áreas relacionadas con
Machine Learning, análisis de datos y desarrollo de soluciones basadas en IA.
